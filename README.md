## 📝 Overview
**Unity Mario Platformer (2D)** is a side-scrolling game inspired by the legendary **Super Mario** series.  
Players guide their character through colorful and challenging levels filled with hazards, coins, power-ups, and classic enemies.  
The gameplay captures Mario’s core mechanics — run, jump, break blocks, and reach the flagpole — built using **Unity’s 2D tools** and modular **C# code**.  

This project is perfect as a foundation for **learning, modding, or building your own platformer adventure** 

---

## ✨ Features
- 🎯 Faithful recreation of Mario-style movement, physics, and controls.  
- 🧱 Multiple block types: **breakable, coin, question, and solid**.  
- 💰 Collectibles: **coins, mushrooms, and power-ups** with player transformations.  
- 👾 Classic enemies like **Goomba** and **Koopa**, each with unique AI and defeat logic.  
- 🗺️ **Tilemap-based level design** for fast and flexible creation.  
- 🎥 Side-scrolling camera that smoothly follows the player.  
- 🏁 Level completion with flagpole and castle animation sequence.  
- ⌨️ Responsive input (Arrow keys / WASD) with smooth movement and jumping.  
- 🧩 Organized and extensible project structure.  
- 🔊 Basic sound effects and placeholder visuals (fully customizable).

## 🚀 Getting Started

### 🧰 Prerequisites
- **Unity Hub** and **Unity Editor** (**2024.3 LTS** or newer recommended)  
- Basic familiarity with **Unity** and **C#** is helpful  

### ⚙️ Installation
1. Clone or download this repository to your computer.  
2. Open the project in **Unity Hub**.  
3. Load the main scene (e.g. `MainScene.unity` or `1-1-Grid`).  
4. Press **Play** in the Unity Editor to start.

## 📁 Project Structure

| Folder | Description |
|---------|-------------|
| `/Assets/Scripts` | Core C# scripts (player, enemies, items, etc.) |
| `/Assets/Scenes` | Unity scenes (levels) |
| `/Assets/Tilemaps` | Tilemaps for level layout and decoration |
| `/Assets/Sprites` | Sprite images for characters, items, and environment |
| `/Assets/Audio` | (Optional) Sound effects and background music |
